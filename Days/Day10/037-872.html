037. Leaf-Similar Trees

Difficulty: Easy

Description

Consider all the leaves of a binary tree, from left to right.

The values of those leaves form a leaf value sequence.

Two binary trees are considered leaf-similar if their leaf value sequences are identical.

Return true if the two given trees are leaf-similar, otherwise return false.

Examples

Input:
root1=[3,5,1,6,2,9,8,null,null,7,4]
root2=[3,5,1,6,7,4,2,null,null,null,null,null,null,9,8]

Output:
true

Explanation:
Leaf sequence of root1=[6,7,4,9,8]
Leaf sequence of root2=[6,7,4,9,8]

Both sequences are identical.

Input:
root1=[1,2,3]
root2=[1,3,2]

Output:
false

Explanation:
Leaf sequence of root1=[2,3]
Leaf sequence of root2=[3,2]

Sequences are different.

Constraints

The number of nodes in each tree is in the range [1,200].
0<=Node.val<=200

Idea (One Line)

Traverse both trees using DFS, collect leaf nodes from left to right, then compare the two leaf sequences.

Pseudocode (DFS Collect Leaves)

function leafSimilar(root1,root2)
    leaves1=emptyList()
    leaves2=emptyList()

    collectLeaves(root1,leaves1)
    collectLeaves(root2,leaves2)

    return leaves1==leaves2


function collectLeaves(node,leaves)
    if node==null
        return

    if node.left==null and node.right==null
        append node.val into leaves
        return

    collectLeaves(node.left,leaves)
    collectLeaves(node.right,leaves)

Complexity

Time Complexity: O(n+m)
Space Complexity: O(n+m)

n=nodes in first tree
m=nodes in second tree

Code Explanation

1. Create two empty lists leaves1 and leaves2.
2. Traverse first tree using DFS.
3. Whenever a leaf node is found, store its value.
4. Traverse second tree similarly.
5. Compare both leaf sequences.
6. If equal, return true.
7. Otherwise return false.

Other Patterns

1. Iterative DFS Using Stack

Idea

Use stack to traverse tree and collect leaf nodes.

Pseudocode

function leafSimilar(root1,root2)
    leaves1=getLeaves(root1)
    leaves2=getLeaves(root2)

    return leaves1==leaves2


function getLeaves(root)
    leaves=emptyList()
    stack=emptyStack()

    push root into stack

    while stack not empty
        node=pop stack

        if node.left==null and node.right==null
            append node.val into leaves

        if node.right!=null
            push node.right into stack

        if node.left!=null
            push node.left into stack

    return leaves

2. BFS Level Order

Idea

Traverse using queue and record leaves from left to right.

Pseudocode

function leafSimilar(root1,root2)
    leaves1=getLeaves(root1)
    leaves2=getLeaves(root2)

    return leaves1==leaves2


function getLeaves(root)
    leaves=emptyList()
    queue=emptyQueue()

    enqueue root into queue

    while queue not empty
        node=dequeue queue

        if node.left==null and node.right==null
            append node.val into leaves

        if node.left!=null
            enqueue node.left into queue

        if node.right!=null
            enqueue node.right into queue

    return leaves

3. DFS Generator Style

Idea

Generate leaves one by one and compare sequences lazily.

Pseudocode

function leafSimilar(root1,root2)
    seq1=getLeafSequence(root1)
    seq2=getLeafSequence(root2)

    return seq1==seq2

Comparison of Approaches

Approach Idea Time Space Recommended
Recursive DFS Collect leaves recursively O(n+m) O(n+m) ⭐⭐⭐⭐⭐
Iterative DFS Stack traversal O(n+m) O(n+m) ⭐⭐⭐⭐
BFS Queue traversal O(n+m) O(n+m) ⭐⭐⭐
Generator DFS Generate leaves lazily O(n+m) O(h) ⭐⭐⭐

where

n=nodes in first tree
m=nodes in second tree
h=height of tree

Best Choice

Interview: Recursive DFS

Reason:
1. Very simple and intuitive.
2. Naturally traverses leaves from left to right.
3. Easy to implement and debug.
4. Most common solution for LC 872.
